## MODIFIED Requirements

### Requirement: 列表摘要与完整详情分离
系统 SHALL 保留完整对象接口，并为任务、Case、共享数据、归档及执行列表提供摘要和分页，默认20条、上限100条；handoff状态 SHALL 不构建函数目录、Schema或完整Generation。共享 Case 的 view SHALL 保留 published/mine 权限含义，以 representation=summary/full 区分表现形式；其余既有 view=summary 保持兼容。

#### Scenario: 浏览列表再打开详情
- **WHEN** 用户浏览某页摘要并选择具体记录
- **THEN** 列表从数据库有界筛选，详情按精确ID读取完整事实，分页不丢失可浏览记录

#### Scenario: 分组计数与历史权限
- **WHEN** 浏览共享接口目录、Case分组或某Case执行历史
- **THEN** 在分页前按员工、基准、接口、环境及精确版本授权；目录只读计数，分组和子项分别分页，执行历史先筛选摘要再按需解压详情
- **AND** 历史缺少选择字段时只扫描有界候选窗口并返回真实下一游标；不能确定总数时保持未知

#### Scenario: 旧执行缺少新版逐项摘要
- **WHEN** 当前授权页或固定请求回执中的旧执行尚未保存逐项摘要字段
- **THEN** 仅批量读取这些候选的原始正文，核对范围及精确选择后派生真实结果，不改写历史；已经存在的摘要字段即使为空也不回读正文
- **AND** 原记录缺少时间仍显示未记录，正文缺失、损坏或身份不一致明确报错，不冒充成功或没有记录

#### Scenario: 大分组和完整范围搜索
- **WHEN** 一个模板有跨页参数变体，或用户搜索的 Case 不在当前页
- **THEN** 数据库先对全部授权成员归组和搜索，再分页读取组代表或成员；命中组内任一成员时保留完整分组及准确计数
- **AND** 参数正文和执行准入字段仅读取本页成员，统计所需窄字段可扫描全部授权范围；百分号和下划线按搜索文字处理

#### Scenario: 完整覆盖报告复用可见性索引
- **WHEN** 用户按需读取含多个增强 Case 的完整覆盖报告
- **THEN** 基础、复测和增强绑定共用一次批量权限核验，标题从本次已读取的精确增强内容取得，不逐条重读 Case 或 Generation
- **AND** 不可见绑定不暴露标题，固定执行选择失效仍返回不可查看原因，查询异常不能伪装成无覆盖记录
