# Simplify Java system onboarding

## Why
A dependency DTO gap and an inapplicable legacy Job diagnostic prevent reliable interfaces, resources and relations from being published. Resource connection checks depend on unrelated business profiles. Mandatory background confirmation, inconsistent UI and legacy runtime storage add friction.

## What Changes
- Resolve local and external contracts with existing source and exact Maven/JAR readers; publish reliable partial results without AI parsing.
- Probe discovered resources using selected project environments independently of business validation profiles.
- Generate three editable background sections; unify console feedback and controls.
- Make MySQL the sole runtime store and remove verified disposable local files while retaining local-only archives/configuration.
- After deterministic verification, use existing Agent tasks for evidence-validated unknown contract gaps.

## Impact
Source analysis, operation contracts, relations, resource workers, knowledge workflow, console and runtime storage. Frozen historical versions remain unchanged. No new persistent tables or general-purpose framework.
