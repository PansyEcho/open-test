# Why

共享工作台目前依赖各自的YAML、Markdown、JSON与机器路径，接口关系按系统两层展开，契约和覆盖资产未在扫描中完整持久化，无法可靠复用与检查回归遗漏。

# What Changes

- 将共享系统、扫描、接口契约、知识、Case、数据函数、工作流和执行记录迁至远端MySQL，保留Git源码及本地配置与执行进程。
- 按固定扫描持久化基础契约、接口级依赖和程序覆盖事项；新系统发布自动补全双方当前关系。
- 数据准备只按场景未满足输入选择具体操作，保留未知并避免系统范围扩散。
- V4冻结生产源码基线和覆盖清单，程序检查AI遗漏；执行增加前后观察，必要MQ/RPC观测源缺失直接观察失败。
- 版本化缓存大扫描和工具包，迁移机器路径并维护多工作台任务归属。

# Impact

修改现有存储适配器、应用装配、扫描器、契约和关系服务、V4编译执行、任务管理及相关API投影。使用现有PyMySQL和Pydantic模型，不引入新平台。目标数据库已确认MySQL 8.4.10，app_db为空；连接凭据仅存本地忽略配置。
