# Design

- 单个 HTML 内嵌固定版本 Three.js，直接从文件打开时不发起资源请求。
- 从已还原的 26 个可见块开始应用全部指定打乱；只选择对应外层旋转，记录整数坐标与离散朝向，避免浮点误差累积。
- 开发时用 cube.js 的 Kociemba 双阶段算法根据打乱后的状态求解，将独立搜索得到的面转序列嵌入 HTML；页面启动时用贴纸坐标模型校验打乱及解法，不用打乱逆序作为解法。
- 固定正交相机，坐标 +Y 白、-Y 黄、+Z 绿、-Z 蓝、+X 红、-X 橙；不启用 OrbitControls 或整体旋转。
- 使用单调时钟和绝对时间线：第 n 步起点为 n×400ms、终点为 n×400+350ms。末步不计尾部暂停；54 个贴纸与网格实际朝向都通过后才显示成功。
- 页面为独立静态作品，没有跨后端重启的状态写入；所有 JS/CSS 内嵌，无需外部资产 URL 或页面版本轮询。
