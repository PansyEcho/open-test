# 实现决策
- 普通系统PUT复用已有元信息更新和本地配置保存，不创建扫描任务；新建仍自动扫描。
- 接口跨版本关系只用于发现和展示，保存调用与发布版本并标记差异；未知或歧义不能自动选为执行目标。仅更新当前派生关系。
- 内存缓存仅服务于系统列表、扫描目录、关系与知识目录的重复HTTP读取，最多32项、估算32MiB。每次请求读取所有系统的workspace_revision/latest_scan_id/归档状态及本机源码绑定文件状态，版本变化即重建；不使用TTL，不缓存扫描历史、任务或执行判断。契约、后补接口和草稿写入与版本推进同事务提交，回滚不使缓存失真。
- 高级DSF诊断按需加载，配置页的正常路径不再触发全局操作合并。MQ关系和真正未解析问题仍可查看。
