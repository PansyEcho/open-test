## Why

回归 Case 的环境目录约 40 ms，但页面先等待约 14.7 秒的扫描历史；历史请求重复完整解析全部扫描。入口选择无法过滤。createOrder 的枚举被同时投影为字符串和带子字段的对象，保存的 BLOCKED 输入契约持续阻止生成。

## What Changes

- 入口使用可输入过滤的单选下拉框，保留现有版本、历史入口和系统隔离行为。
- 系统确定后优先读取环境并展示加载、无配置和失败状态。
- 按文件状态缓存有界扫描摘要，消除重复全量读取，直接读取 latest 指针。
- 枚举保持叶子字段，统一整理后的字段和请求 Schema；已有 BLOCKED 契约从绑定扫描重新校验。

## Impact

影响回归页面、扫描历史查询及 Case 输入契约推导；API 响应格式不变，不新增依赖，不改变历史知识或执行 QA。
