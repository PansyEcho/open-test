# Case 与执行结果的可读展示

## Why

现有 Case 页面主要展示内部身份和 JSON，难以阅读场景、参数变化和真实执行结果。沿用既有模板、子用例和独立执行批次，提供只读业务展示。

## What Changes

- 回归 Case 仅保留用例与执行结果两个页签，用单一详情抽屉连接场景和子用例。
- 复用字段树、子用例对比和断言对照，分离变化维度、值来源、计划和实际。
- 按版本、环境、批次隔离统计，复用轮询并保留选择、展开和滚动状态。
- 执行 GET 查询保留原始字段存在性，明确区分缺失、空值与无法判定的旧记录。
- 保留生成、执行、恢复及脱敏行为，不新增持久化模型或执行能力。

## Impact

涉及 v2-console、v2-api、现有静态页面、只读执行查询及相应测试；不修改执行引擎。
