# 实施决策

模板按 template_id 对应场景，Variant 对应子用例，Generation 对应用例版本，Execution 对应环境内的一次执行。前端只读适配使用版本冻结的输入契约、参数绑定、数据函数和有效 Oracle；不重新生成、求值或调用业务操作。

保留现有 app.js 的请求与任务链路，独立 case-view.js 承载本页的只读组件和适配。使用现有 DOM、CSS 变量、抽屉与请求代次。执行 GET 仅省略原始模型中未出现的字段，不过滤已记录的 null、空值、0 或 false，不改变写接口及其他消费者的模型。

当前 case-generation-execution/v1 的显式执行契约纳入绑定 Generation 的全部 Variant（不可运行项产生 BLOCKED）；仅在契约及版本身份都匹配时据此列出完整集合，缺结果项显示“尚无结果记录”，不推断运行阶段。不满足上述证据时仅报告已记录结果数量。执行器目前整批完成才保存结果；保留该事实而不增加逐条持久化。

根据记录的 Operations、assertions 和错误确定展示状态；缺少阶段证据不自动显示通过。清理异常与业务判定分开表达，统计每个子用例只计一次。对原始记录中实际值字段有明确存在性时忠实展示；仅有补值且可靠摘要证明信息不完整时提示无法区分，绝不以真假值或空值过滤判定。

验证使用真实历史记录的只读浏览及隔离的本地测试服务。浏览器必须实际完成四图链路、刷新和复杂字段交互，并保存运行页面截图。任何生产业务调用均不属于验收。
