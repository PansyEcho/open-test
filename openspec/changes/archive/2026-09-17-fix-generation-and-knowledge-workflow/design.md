## Decisions

1. 类型比较接受 JSON Schema 单类型和类型列表，非法或不兼容输入产生定位明确的校验问题。内部失败保留草稿并允许原任务正常重验，保留 revision 和请求回执。
2. 接口知识以现有 OperationContractStore 为唯一正文来源，支持用途、请求及业务响应字段；MQ 解析到消费者消息类型。旧长文和内部模式不进入主目录。
3. 下游展示按调用方 gsName 聚合，与要求提供方注册的执行范围分开；额外接口仅在任务需要时读取固定扫描或调用方明确依赖的本地 Maven 元数据。发现不赋予执行权限。
4. 代码枚举从完整语义扫描确定，不依赖入口影响范围；规范化旧候选时保留人工说明和忽略状态。HTTP Job 退役不删除同名 DSF Facade。
5. 网页 Runner 退出后才能切 native；接续 API 与启动/答案共用任务锁。切换后答案不得重新启动网页 Runner；只有成功回执包含原会话链接。

## Verification

针对原草稿、原枚举和真实 Refund 下游进行回归；HTTP 验证版本化资源、接续请求先于深链、native 答案不启动后台。仅恢复和发布原 Case，不执行 QA。任务差异使用临时基线隔离，初测后完成一次 OCR delegation 审查。
