# Change: 修复V4控制台迟到错误串写

## Why

V4页面已经用请求代次拒绝失效请求的成功响应，但旧handoff轮询或首次状态读取在用户切换到Generation历史后才失败时，异常处理仍可能覆盖用户刚选择的JSON视图。这是已归档V4控制台契约中“迟到成功和迟到错误都不得串写”的尚未闭合实现差异，需要作为活动进度显式保留。

## What Changes

- 让V4 handoff状态读取的异常携带并校验发起时的请求代次和视图身份。
- 用户切换到Generation历史后，静默丢弃旧轮询或旧启动流程的迟到错误。
- 增加迟到成功与迟到失败两条浏览器异步竞态测试，并通过运行中的HTTP服务验收。

## Scope

只修复V4控制台共享状态和JSON区域的请求隔离，不修改后端handoff、DSL、执行语义或Generation持久化。
