# Change: 共享数据准备与有限跨系统联调

## Why

Case 数据函数目前只能在单个 Generation 内复用，接口契约依赖知识长文发布，跨系统环境和权限没有贯通到执行末端。需要让 Case 和独立自然语言任务共用可验证的数据准备方法，同时沿用已有不可变 Generation、Operation、Worker 和任务记录。

## What Changes

- 将输入输出契约从内部知识长文解耦，按指定源码版本与执行路径证据补充约束；停止长文和回归点资产作为前置。
- 发布版本化 JSON 数据能力，复用有限数据 DSL，支持查询、必要时创建或有限状态调整、结果验证及独立执行。
- 从DSF/MQ扫描汇总只读关系，分别沿上下游广度优先查找最多两层；取消人工绑定、逐关系操作和用途授权。固定扫描Operation不重新选择latest。
- 复用 Generation 内嵌数据定义；运行结果独立保存，停止当前清理执行及其完成判定。
- 增加共享数据能力页面和统一任务中心，业务页面展示相关任务及数据来源，报告区分失败性质。

## Non-Goals

不引入数据库迁移、企业 Agent 平台、任意脚本、无界递归发现、通用工作流、自动清理或补偿。不删除历史资产，不伪造业务数据或更改用户条件。不新增基线快照库。

## Approved refinement

每项目只维护逻辑qa/uat，实际filter与路由使用项目自身配置（qa/test/dev/uat）。同一执行预先解析相关项目Profile后保持一致，不维护项目间环境映射。关系图只用于新任务发现；既有Generation保留固定源码范围，历史配置和记录不改写。
