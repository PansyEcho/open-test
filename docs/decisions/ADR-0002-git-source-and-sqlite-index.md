# ADR-0002：Git真相源与SQLite派生索引

## 状态

已接受。

## 决策

知识内容使用Markdown/YAML提交Git；SQLite FTS5仅保存可从文件重建的节点、关系、别名和全文索引。当前阶段不使用向量数据库。

## 原因

- Git提供审计、评审、回滚和Agent可读性。
- SQLite无需服务进程，适合本地反向关系和全文查询。
- 代码符号和业务术语优先依赖精确、别名和关系检索。

## 结果

- SQLite文件不得包含无法从Git知识文件恢复的业务数据。
- 删除索引后必须能确定性重建。
- 是否增加embedding由真实黄金查询评测决定。
